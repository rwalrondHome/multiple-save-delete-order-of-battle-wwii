# Multiple Save Delete Plugin for Order of Battle: World War II

## Description

This BepInEx plugin allows you to select and delete multiple save games at once in Order of Battle: World War II, saving you from having to remove old saves one by one.

## Requirements

- Order of Battle: World War II (PC)
- BepInEx 5 (x64 / 64-bit version for Unity Mono games)

## Installation

1. Download and install BepInEx 5 into your main game folder (where `Order of Battle - WW2.exe` is located).
   - Run the game once after installing BepInEx so it generates the required configuration folders.
2. Locate your game's plugin directory: `...\Order of Battle Pacific\BepInEx\plugins\`
   - If the `plugins` folder does not exist yet, create it manually.
3. Copy the plugin `.DLL` file from the archive into the `plugins` folder.
4. Launch the game. The plugin will load automatically.

## How to Use

Open the Load/Save menu. Checkboxes appear to the left of the save file names. Select one or more rows, then click **Delete** to delete all selected saves.

You can also click the checkbox at the top, next to the **Filename** heading, to select or deselect all save files.

If you have a lot of save files, loading the selection controls can take a while, so please be patient.

## Uninstallation

Delete the plugin `.DLL` file from your `Order of Battle Pacific\BepInEx\plugins\` folder.
